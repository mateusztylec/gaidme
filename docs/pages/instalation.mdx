# Instalation

### Requirements

- Python 3.8 or higher

### Installation

For linux, macos and windows you can install gaidme using pip:
```bash
pip install gaidme
```

Alternatively, you can install gaidme using pipx:
```bash
pipx install gaidme
```

### Follow steps

To add your API key, you can use the `/settings` command.

```bash
gaidme
```
then type `/settings` and choose "Change API key".

Generate your API key at [gaidme.app](https://gaidme.app/dashboard/api-keys).
